# 🌦️ Weather Detection using Python

## 📌 Overview
This project is a Weather Detection Web Application built using Python and HTML. It allows users to check weather conditions based on location input. The system processes weather data and displays relevant weather information such as temperature, weather condition, and environment status.

This project demonstrates practical implementation of Python programming, web integration, and real-world application development.

---

## 🚀 Features
- Detects weather based on user input
- Displays temperature and weather condition
- Simple and user-friendly interface
- Lightweight and fast execution
- Beginner-friendly Python project

## ⚙️ Installation

### Step 1: Clone the repository

### Step 2: Navigate to the project folder

cd weather_detection


### Step 3: Install required libraries (if needed)

pip install requests


---

## ▶️ Usage

Run the Python file:


python c.py


Then open the HTML file:


webpage.html


Enter the location to get weather information.

---

## 🧠 How it Works

1. User enters location
2. Python processes the input
3. Fetches weather data
4. Displays weather condition
5. Shows temperature and status
